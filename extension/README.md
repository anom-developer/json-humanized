# 🌐 json-humanized — Browser Extension (Chrome, Edge, Brave, Opera)

Превращайте любой сырой **JSON, YAML и TOML** в понятный человеческий язык прямо в вашем браузере в один клик!

---

## ⚡ Быстрая установка (15 секунд, без терминала)

1. Откройте любой браузер на базе Chromium (Google Chrome, Яндекс.Браузер, Microsoft Edge, Brave, Opera).
2. Перейдите по адресу:
   - В Chrome / Brave: `chrome://extensions`
   - В Edge: `edge://extensions`
   - В Яндекс.Браузере: `browser://extensions`
3. В правом верхнем углу включите переключатель **«Режим разработчика»** (*Developer mode*).
4. Нажмите появившуюся кнопку **«Загрузить распакованное расширение»** (*Load unpacked*).
5. Выберите папку `extension` из этого проекта (`json-humanized/extension`).
6. Готово! Иконка 🗣️ появится в панели расширений вашего браузера.

---

## 🚀 Возможности расширения:

1. **Всплывающее окно (Popup)**:
   - Вставьте JSON / YAML / TOML или просто перетащите файл мышкой (Drag & Drop).
   - Выберите язык: **🇷🇺 Русский** или **🇬🇧 English**.
   - Нажмите **«Humanize →»** и получите связный понятный текст.
   - Кнопка **«🔊 Listen»**: озвучивание текста голосом через синтезатор речи!
   - Кнопка **«📋 Copy»** и **«💾 Save»** (скачать файлом).

2. **Кнопка «📥 Page»**:
   - Открыли в браузере API-эндпоинт (например, `api.github.com/users/octocat`)?
   - Нажмите значок расширения и кнопку «📥 Page» — расширение само заберет JSON со страницы и переведет его на понятный язык!

3. **Контекстное меню (ПКМ)**:
   - Выделите любой текст JSON на любом сайте.
   - Нажмите правую кнопку мыши → **«🗣️ Humanize JSON (json-humanized)»**.
   - Появится красивое всплывающее окно с расшифровкой данных.

4. **Вкладка «Diff» (Сравнение)**:
   - Вставьте версию А и версию Б.
   - Получите четкое описание: что было добавлено, удалено или изменено простыми словами.

5. **100% автономность**:
   - По умолчанию работает полностью офлайн (без интернета, без ключей API).
   - При желании во вкладке «Settings» можно подключить Claude, OpenAI или локальную Ollama.
