🗣️ Инструкция по установке (Для обычных пользователей)

Вам не нужно знать терминал или уметь программировать! Выберите любой удобный способ:

1. 🌐 Установка расширения в браузер (Chrome, Edge, Яндекс, Brave)

  1. В браузере откройте адрес: chrome://extensions (в Edge: edge://extensions, в Яндекс.Браузере: browser://extensions).
  2. В правом верхнем углу включите тумблер «Режим разработчика» (Developer mode).
  3. В левом верхнем углу нажмите кнопку «Загрузить распакованное расширение» (Load unpacked).
  4. Выберите папку extension из проекта и нажмите «Выбор папки».
  5. Готово! Значок 🗣️ появится в панели расширений. Можно выделять любой JSON на любом сайте и через правую кнопку мыши мгновенно его очеловечивать!

2. 💻 Запуск программы на компьютере в 1 клик

Просто дважды кликните по файлу start-ui.bat (для Windows) или start-ui.sh (для Mac/Linux). Браузер сам откроет приложение со всеми функциями!

3. 🔌 Расширение для редактора VS Code

Скопируйте папку vscode-extension в папку .vscode/extensions на вашем компьютере. При клике правой кнопкой мыши по любому JSON-файлу появится пункт «🗣️ json-humanized: Transform to Human Language».
